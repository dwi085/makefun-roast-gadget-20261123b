A [make.fun](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) entry for "One-Line Roast: The Gadget You Use Every Day".

`main.ts` (Node 22) writes one original roast line — at most 200 characters — about the phone battery that gives up by four in the afternoon, to `entry.txt`. Deterministic: two runs produce byte-identical output, no network, no randomness.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
